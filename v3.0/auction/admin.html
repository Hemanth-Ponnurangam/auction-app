📋 CSV FORMAT TEMPLATE
name, base_price, set, role, nationality, national_board, franchise, [stat_1 … stat_6]
✔ name — Player full name
✔ base_price — In Crores (e.g. 2.5 = ₹2.5 Cr)
✔ set — e.g. Marquee, Capped, Uncapped
✔ role — BAT / BOWL / ALL / WK
✔ nationality — e.g. Indian, Australia
✔ national_board — e.g. BCCI, ECB, CA
✔ franchise — Previous IPL/league franchise e.g. RCB
★ Stats (optional, max 6) — Any column names e.g. matches, runs, wickets, average, economy, strike_rate
Example row: Virat Kohli, 2.5, Marquee, BAT, Indian, BCCI, RCB, 237, 8263, 48.7, 139.1
